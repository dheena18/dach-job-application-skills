# German Anschreiben structure (DIN 5008)

## Length and shape

- One page, 250-400 words, 3-4 Absätze.
- Same font and header treatment as the resume (see `visual-consistency.md`).
- Formal by default. Match "Du" only if the posting itself uses "Du"
  throughout — never initiate it.
- Sign-off "Mit freundlichen Grüßen" for Germany; "Freundliche Grüsse" for
  Switzerland (also: no ß, write "ss" everywhere in a Swiss letter); Austria
  uses German conventions but titles matter on the recipient line
  ("Sehr geehrter Herr Mag. Huber").

## Layout

```
Vorname Nachname
Straße Nr.
PLZ Ort
Telefon · E-Mail

Firma GmbH
Frau/Herr Vorname Nachname (Abteilung, falls bekannt)
Straße Nr.
PLZ Ort

                                                        Ort, [TT. Monat JJJJ]

Bewerbung als [Stellentitel exakt wie in der Anzeige], Kennziffer [falls vorhanden]

Sehr geehrte Frau/Sehr geehrter Herr [Nachname], (Fallback: Sehr geehrte Damen und Herren,)

[Absatz 1 — Aufhänger]

[Absatz 2 — Belege]

[Absatz 3 — Passung]

[Absatz 4 — Schluss]

Mit freundlichen Grüßen

Vorname Nachname

Anlagen: Lebenslauf[, Arbeitszeugnisse, Abschlusszeugnisse]
```

- Subject line ("Bewerbung als ...") is bold, no "Betreff:" prefix.
- Named recipient if the posting or LinkedIn gives one; "Sehr geehrte Damen
  und Herren" is the fallback and a weak one — worth a few minutes looking
  for a name first.

## The four Absätze

1. **Aufhänger.** A concrete reason this company, this role — a product,
   a project, a technical decision the company actually made and can be
   checked (see the pattern in `persuasion-and-evidence.md`). Never
   "hiermit bewerbe ich mich" or "mit großem Interesse habe ich Ihre
   Anzeige gelesen."
2. **Belege.** Two or three results with numbers, matched directly to the
   posting's main requirements. Not a prose rerun of the Lebenslauf. Use
   the CAR framework from `persuasion-and-evidence.md`.
3. **Passung.** Why this Unternehmen, this Team, this Aufgabe — one
   concrete, checkable detail about the company. This is also where the
   obvious question gets answered if there is one (gap, Quereinstieg,
   Umzug, Sprachniveau, Aufenthaltstitel) — see `gap-and-weakness-framing.md`.
4. **Schluss.** Eintrittstermin or Kündigungsfrist, Gehaltsvorstellung if
   asked for ("Meine Gehaltsvorstellung liegt bei [Betrag] Euro brutto im
   Jahr."), one sentence inviting a conversation.

## Register: sachlich, not stiff

German default is sachlich/zurückhaltend — personality comes through in
specific factual claims, not adjectives or superlatives. See
`tone-and-culture-calibration.md` for the full EN/DE contrast and for when
(startups, creative agencies) more personality is appropriate. Never
translate an English-language "direct and confident" register word-for-word
into German; it reads as unseriös.

## Non-native German

Keep sentences short — a short, correct letter beats a long one with
errors. If drafting from an English original, translate for meaning, not
word by word, and keep established technical terms (LLM, RAG, etc.) as
they already appear on the resume, not spelled out differently here — see
`cv-translate-de`'s terminology rules for the same consistency requirement.

## English applications to German companies

Keep the DACH expectations that still apply even when the letter itself is
in English: a subject line with the exact job title and reference number,
city/country in the header, and answering any hard-requirement gap the
posting names. See `germany-dach.md`-style guidance already used by
`resume-tailor`'s `german-tailoring.md` for the broader market context.

## Verify list

Before delivering: contact name spelling, company legal name (GmbH/AG/etc.
exactly), job title exactly as written in the posting, Kennziffer, every
number in the letter, the date, and that "Sie" was used throughout unless
the posting genuinely uses "Du."
